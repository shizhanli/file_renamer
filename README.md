# file_renamer

依檔案修改時間 mtime 批次重新命名檔案，支援 preview 與 apply 2 種模式，並輸出 CSV 報表。

## 1 核心概念

1 preview 只產生改名規劃與報表，不會改動任何檔案  
2 apply 會真的執行改名，並輸出改名後的結果報表  
3 以每個資料夾為單位各自編號，同一秒內用序號避免檔名重複  
4 預設忽略隱藏資料夾與隱藏檔案，也就是名稱以 . 開頭者不處理  

## 2 命名規則

新檔名格式

YYYYMMDD_HHMMSS_序號2位數 原副檔名

例子

20260103_154501_01.jpg  
20260103_154501_02.jpg  
20260103_160010_01.pdf  

說明

1 時間來自檔案最後修改時間 mtime  
2 同一資料夾內若同一秒有多個檔案，序號會遞增 01 02 03  
3 副檔名沿用原檔案副檔名
