# file_renamer

依檔案修改時間 mtime 批次重新命名檔案，支援 preview 與 apply 2 種模式，並輸出 CSV 報表。

## 1 功能概述

此工具會遞迴掃描指定資料夾內的檔案，並以每個資料夾為單位，依檔案修改時間 mtime 產生新檔名。

提供 2 種模式  
1 preview 只預覽改名計畫並輸出報表，不會變動檔案  
2 apply 會實際執行改名，並輸出結果報表

若產生的新檔名與現有檔案衝突，會跳過並在報表中記錄原因。

## 2 功能特色

1 遞迴掃描指定資料夾，包含子資料夾  
2 排除隱藏資料夾與隱藏檔案  
3 以每個資料夾為單位建立改名計畫  
4 新檔名以 mtime 轉成時間戳記並加上同秒序號，避免同秒多檔同名  
5 輸出 CSV 報表，方便檢查與追蹤

## 3 環境需求

1 Python 3.10 以上  
2 不需安裝第三方套件，僅使用 Python 標準函式庫

## 4 檔名規則

新檔名格式  
YYYYMMDD_HHMMSS_序號.副檔名

說明  
1 YYYYMMDD_HHMMSS 來自檔案的 mtime  
2 序號為 2 位數，同一個資料夾內，同一秒內自動遞增，例如 01 02 03  
3 副檔名沿用原檔案副檔名

範例  
20260103_120501_01.jpg  
20260103_120501_02.jpg  
20260103_121010_01.pdf
